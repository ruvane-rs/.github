# Ruvane organization profile

Public profile content and visual assets for [Ruvane](https://github.com/ruvane-rs).

- [`profile/README.md`](profile/README.md) is displayed on the organization overview.
- [`profile/assets/`](profile/assets/) contains the light and dark SVG banners.
- [`LICENSE`](LICENSE) covers this repository under the MIT license.

The banners reuse the Ruvane logo and contain no external fonts or scripts.
The profile uses absolute image URLs so it also renders on the organization page.

When publishing a new framework release, update the installation command,
versioned documentation link, and feature availability note in the profile.
The crates.io version badge updates automatically.

See [GitHub's organization profile documentation](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).
